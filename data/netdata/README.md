# NetData input

The benchmark uses `Performance_5G_Weekday.csv` from the NetData repository at
commit `093e13ebcbee4f18a3fc4d6a6f3aeab9ac1283a3`. The upstream repository does
not declare a redistribution license, so the CSV is not part of this release.

Run `python3 fetch_netdata.py` from the artifact root to download the pinned
file and verify SHA-256
`33a4a1530d6a871807ffae0a498a803c5631fd5edc33138369fdf88bf3a9f0a0`.
The MIT license at the artifact root applies to benchmark code, not to this
third-party dataset.
